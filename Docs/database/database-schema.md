# StudyFlow AI — Database Schema

## 1. users

Stores registered StudyFlow users.

| Column | Type | Constraints |
|---|---|---|
| id | BIGSERIAL | PRIMARY KEY |
| name | VARCHAR(100) | NOT NULL |
| email | VARCHAR(255) | NOT NULL, UNIQUE |
| password_hash | VARCHAR(255) | NOT NULL |
| timezone | VARCHAR(50) | NOT NULL |
| created_at | TIMESTAMP | NOT NULL |
| updated_at | TIMESTAMP | NOT NULL |

---

## 2. semesters

Stores academic semesters created by users.

| Column | Type | Constraints |
|---|---|---|
| id | BIGSERIAL | PRIMARY KEY |
| user_id | BIGINT | NOT NULL, FK → users.id |
| name | VARCHAR(100) | NOT NULL |
| start_date | DATE | NOT NULL |
| end_date | DATE | NOT NULL |
| active | BOOLEAN | NOT NULL, DEFAULT FALSE |
| created_at | TIMESTAMP | NOT NULL |
| updated_at | TIMESTAMP | NOT NULL |

Relationship:

User 1 → N Semesters

---

## 3. courses

Stores courses belonging to a semester.

| Column | Type | Constraints |
|---|---|---|
| id | BIGSERIAL | PRIMARY KEY |
| semester_id | BIGINT | NOT NULL, FK → semesters.id |
| name | VARCHAR(150) | NOT NULL |
| code | VARCHAR(50) | NULL |
| difficulty | SMALLINT | NOT NULL |
| importance | SMALLINT | NOT NULL |
| color | VARCHAR(20) | NULL |
| created_at | TIMESTAMP | NOT NULL |
| updated_at | TIMESTAMP | NOT NULL |

Relationship:

Semester 1 → N Courses

---

## 4. deadlines

Stores exams, assignments, quizzes, projects, presentations, and other academic deadlines.

| Column | Type | Constraints |
|---|---|---|
| id | BIGSERIAL | PRIMARY KEY |
| course_id | BIGINT | NOT NULL, FK → courses.id |
| title | VARCHAR(200) | NOT NULL |
| type | VARCHAR(30) | NOT NULL |
| due_at | TIMESTAMP | NOT NULL |
| estimated_minutes | INTEGER | NOT NULL |
| completed_minutes | INTEGER | NOT NULL, DEFAULT 0 |
| importance | SMALLINT | NOT NULL |
| status | VARCHAR(30) | NOT NULL |
| created_at | TIMESTAMP | NOT NULL |
| updated_at | TIMESTAMP | NOT NULL |

### Deadline Types

- EXAM
- QUIZ
- ASSIGNMENT
- PROJECT
- PRESENTATION
- OTHER

### Deadline Status

- PENDING
- IN_PROGRESS
- COMPLETED
- CANCELLED

Relationship:

Course 1 → N Deadlines

---

## 5. study_availability

Stores recurring periods during which a user is available to study.

| Column | Type | Constraints |
|---|---|---|
| id | BIGSERIAL | PRIMARY KEY |
| user_id | BIGINT | NOT NULL, FK → users.id |
| day_of_week | SMALLINT | NOT NULL |
| start_time | TIME | NOT NULL |
| end_time | TIME | NOT NULL |
| active | BOOLEAN | NOT NULL, DEFAULT TRUE |

Relationship:

User 1 → N Study Availability Records

---

## 6. study_plans

Represents a generated study schedule.

| Column | Type | Constraints |
|---|---|---|
| id | BIGSERIAL | PRIMARY KEY |
| user_id | BIGINT | NOT NULL, FK → users.id |
| semester_id | BIGINT | NOT NULL, FK → semesters.id |
| start_date | DATE | NOT NULL |
| end_date | DATE | NOT NULL |
| status | VARCHAR(30) | NOT NULL |
| generated_at | TIMESTAMP | NOT NULL |
| updated_at | TIMESTAMP | NOT NULL |

### Study Plan Status

- ACTIVE
- SUPERSEDED
- COMPLETED

Relationships:

User 1 → N Study Plans

Semester 1 → N Study Plans

---

## 7. study_sessions

Stores individual study blocks generated by StudyFlow.

| Column | Type | Constraints |
|---|---|---|
| id | BIGSERIAL | PRIMARY KEY |
| study_plan_id | BIGINT | NOT NULL, FK → study_plans.id |
| user_id | BIGINT | NOT NULL, FK → users.id |
| course_id | BIGINT | NOT NULL, FK → courses.id |
| deadline_id | BIGINT | NULL, FK → deadlines.id |
| title | VARCHAR(200) | NOT NULL |
| scheduled_start | TIMESTAMP | NOT NULL |
| scheduled_end | TIMESTAMP | NOT NULL |
| planned_minutes | INTEGER | NOT NULL |
| actual_minutes | INTEGER | NULL |
| priority_score | DECIMAL(6,2) | NULL |
| status | VARCHAR(30) | NOT NULL |
| started_at | TIMESTAMP | NULL |
| completed_at | TIMESTAMP | NULL |
| created_at | TIMESTAMP | NOT NULL |
| updated_at | TIMESTAMP | NOT NULL |

### Study Session Status

- PLANNED
- IN_PROGRESS
- COMPLETED
- MISSED
- SKIPPED
- CANCELLED

Relationships:

Study Plan 1 → N Study Sessions

Course 1 → N Study Sessions

Deadline 1 → N Study Sessions

---

## 8. subscriptions

Stores the user's RevenueCat subscription state.

| Column | Type | Constraints |
|---|---|---|
| id | BIGSERIAL | PRIMARY KEY |
| user_id | BIGINT | NOT NULL, UNIQUE, FK → users.id |
| revenuecat_customer_id | VARCHAR(255) | NULL |
| entitlement | VARCHAR(100) | NULL |
| product_id | VARCHAR(255) | NULL |
| status | VARCHAR(30) | NOT NULL |
| expires_at | TIMESTAMP | NULL |
| updated_at | TIMESTAMP | NOT NULL |

### Subscription Status

- FREE
- TRIAL
- ACTIVE
- EXPIRED
- CANCELLED

Relationship:

User 1 → 0..1 Subscription
